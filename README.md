# FreshMarket - Grocery Ordering App

FreshMarket is a simple, elegant, and modern full-stack grocery ordering application built with Java Spring Boot and a custom HTML/CSS frontend. It demonstrates a clean architecture and a premium user interface without pulling in heavy frontend frameworks.

## Features

-   **Premium UI/UX**: A modern, responsive design with glassmorphism effects and smooth transitions.
-   **Product Catalog**: Browse a curated list of fresh groceries with high-quality images.
-   **Shopping Cart**: Add items, adjust quantities, and view real-time totals.
-   **Checkout System**: Simple checkout process (mocked for demonstration).
-   **Backend API**: Robust RESTful API serving product data and handling orders.

## Tech Stack

-   **Backend**: Java 17, Spring Boot 3.2, Spring Data JPA, H2 Database.
-   **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+).
-   **Build Tool**: Maven.
